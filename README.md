# Grand Theft Auto VI (GTA VI) PS5 Trophy Guide & Tracker

Welcome to the ultimate offline PlayStation 5 companion guide and progress tracker for *Grand Theft Auto VI*. Engineered for seamless offline performance with zero external network dependencies, this guide provides everything you need to claim the prestigious **Platinum Trophy ("Vice Got a Price!")** across Vice City and the wider Leonida region.

---

## Guide Features & Architecture

- **Routed Steps per Trophy:** Every single trophy features authored step-by-step routing instructions, exact district locations, difficulty ratings (1-5 stars), time estimates, and missable cutoff mission warnings.
- **Dependency Roadmap:** A structured 5-stage chronological walkthrough roadmap detailing prerequisite stages, estimated hours, and interactive checklist items from campaign start to endgame cleanup.
- **Upgraded Tracker Dashboard:** 
  - **Per-Trophy Personal Notes:** Save custom notes, tips, and reminders for each trophy.
  - **JSON Backup Import/Export:** Securely backup or restore your progress and notes anytime.
  - **Advanced Status Filters:** Filter trophies by Earned, Unearned, **Can Still Get (Safe)**, and **Missable / Missed Risk**.
  - **Live Search & Sorting:** Instant search by name, guide, or steps, with multi-criteria sorting by difficulty, time, and name.
  - **Keyboard Shortcuts:** Power-user navigation (`1-4` views, `/` search, `j`/`k` card navigation, `x` toggle earned, `n` note input, `m` spoiler toggle, `?` help modal).
  - **Done Today Counter:** Track trophies secured during your current session.
  - **Dark / Light Themes:** Instant theme toggling stored locally.
- **Sources & Method Page:** Rigorous editorial attribution citing official Rockstar Games trophy descriptions alongside leading community references (*PowerPyx* and *PSNProfiles*).
- **Accessibility & Spoiler Protection:** Built with semantic ARIA landmarks, keyboard focus management, screen-reader support, and a dedicated **Spoiler Mode** to hide narrative trophy names and descriptions until unlocked.

---

## How to Run

Serve the `app/` directory locally using Python's built-in HTTP server:

```bash
python3 -m http.server -d app
```

Then open `http://localhost:8000` in your preferred web browser. No build steps, external CDNs, or internet connections are required.
