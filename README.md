# GTA VI PS5 Trophy Guide & Tracker

Offline GTA VI PS5 trophy guide and tracker: 55 trophies, roadmap to the platinum, missable flags, localStorage progress with export/import, spoiler mode; sources cited per trophy.

## How to Run

Serve the `app/` directory with Python and open `index.html`:

```bash
python3 -m http.server -d app
```
Then open `http://localhost:8000` (or `index.html`) in your browser.
